Privacy Policy — Electric Insider Uploader

Last updated: October 10, 2026

Electric Insider Uploader ("the tool") is a private command-line tool used only by the owner of the YouTube channel 전기의 속사정 to upload that channel's own videos. The tool uses YouTube API Services. By using the tool you agree to the YouTube Terms of Service and the Google Privacy Policy.

Data accessed

With the channel owner's consent (Google OAuth, scopes youtube.upload and youtube.readonly), the tool accesses: the authenticated channel's ID (to confirm the correct channel), and the ability to upload videos and thumbnails to that channel. It does not access any other YouTube user's data.

How data is used

The channel ID is compared with the owner's channel before each upload. Video files, titles, descriptions, tags and thumbnails are created by the owner and sent to YouTube only to publish them on the owner's channel.

Storage and sharing

The OAuth refresh token is stored only in the macOS Keychain on the owner's computer. No API data is stored on any server, sold, or shared with third parties. The tool does not use cookies, analytics, or advertising.

Revoking access

Access can be revoked at any time at Google Account → Third-party connections, which immediately stops the tool from using the API. Deleting the Keychain item removes the stored token from the computer.
