Privacy Policy — Electric Insider Uploader

Last updated: October 11, 2026

Electric Insider Uploader ("the tool") is a private command-line tool used only by the owner of the YouTube channel 전기의 속사정 to upload that channel's own videos.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service.

Google Privacy Policy

Data handled through YouTube API Services is also subject to the Google Privacy Policy.

Data accessed, used and stored

  • Accessed (with the owner's consent via Google OAuth, scopes youtube.upload and youtube.readonly): the authenticated channel's ID, and permission to upload videos and thumbnails to that channel. No other user's data is accessed.
  • Used: the channel ID is compared with the owner's channel before each upload; the owner's own videos, titles, descriptions, tags and thumbnails are sent to YouTube only to publish them on that channel.
  • Stored: only the OAuth refresh token, in the macOS Keychain on the owner's computer. No API data is stored on any server.
  • Shared: nothing is sold or shared with third parties. The tool uses no cookies, analytics or advertising.

Revoking access

Access can be revoked at any time via the Google security settings page: https://security.google.com/settings/security/permissions. Once revoked, the tool can no longer call the API.

Data deletion

The only stored data is the refresh token. It is deleted from the Keychain immediately when access is revoked or on request, and in any case within 7 days. To request deletion or ask about your data, email the contact below.
